# NC Education (Instructor Site)

এটি শিক্ষক এবং প্রতিষ্ঠানের জন্য তৈরি করা ড্যাশবোর্ড।

## কিভাবে পাবলিশ করবেন:
১. এই ফোল্ডারটি আপনার কম্পিউটার বা গিটহাবে নিন।
২. 'npm install' কমান্ড দিন।
৩. 'npm run build' কমান্ড দিয়ে বিল্ড করুন।
৪. প্রাপ্ত 'dist' ফোল্ডারটি আপনার ডোমেইনে (যেমন nc-education.pages.dev) পাবলিশ করুন।
